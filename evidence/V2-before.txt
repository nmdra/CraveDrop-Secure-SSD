## Baseline source result

- PASS: order-service/src/routes/order.route.js:14 contains `router.get('/:id', getOrderById);`
- PASS: order-service/src/controller/order.controller.js:101 contains `const order = await Order.findById(req.params.id);`
- PASS: order-service/src/controller/order.controller.js:125 contains `const deleted = await Order.findByIdAndDelete(req.params.id);`

Impact: The record lookup and delete operation use only the caller-controlled order id and do not constrain the record to the authenticated customer.
